<objective>
Wave 5, the wave's stack user, beside 04-07: escape search input before it reaches PostgREST (F-082), and measure the escaping against the real parser.

Purpose: REFAC-10's fourth clause and ROADMAP criterion 3 — "`%` and `_` are escaped in search input". 04-RESEARCH.md § Q(f) measured that the ILIKE fallback is not a fallback but the only search path (F-078 makes the fuzzy RPC error on every call), that `.or()` performs no escaping, that a comma returns a PostgREST 400 which the handler turns into a 500 echoing the internal filter, and derived a two-layer escape for which the double-quote and backslash rows are an assumption (A2). This plan ships the escape as a named, unit-tested function and closes A2 with a live probe.

Output: `src/lib/searchFilter.ts` and its tests, the route call site, the moved DEFECT pins in Jest and Playwright, a committed local-only probe, and its evidence.

**Stated, not hidden — and decided, per DEC-32:** escaping changes what a search for a special character returns. On seeded data, a search for `%` or `_` returns both approved events today and none afterwards, because no seeded title contains those characters; a search for `a,b` moves from an API 500 to a 200 with an empty list, while the feed shows the same "No events found" state both times. This plan ships that change unconditionally in wave 5 under DEC-32 (04-01's decision record), which exempts F-082 — and only F-082 — from the 04-11 owner checkpoint that F-080 and F-081 go through. DEC-32's rule: a seeded-visible fix goes to the checkpoint when the ROADMAP clause behind it can be delivered, fully or in part, without the visible change (true of F-080 via 04-10 and of F-081 via 04-07); ROADMAP criterion 3 says "`%` and `_` are escaped in search input" verbatim, and no implementation of that sentence leaves a `%` search's results unchanged, so there is nothing to defer to. F-082 is also an injection-class query defect (a typed `%` becomes match-everything; a comma becomes an anonymous 500 echoing the internal filter), not a presentation choice. Plain-text search results are unchanged, which 04-04's events-list PRESERVE suite (passing unmodified) and the existing "Music Night" UI spec prove. The change is logged in the ledger and the commit body, both citing DEC-32; 04-11's checkpoint lists F-082 as already decided by DEC-32 and not up for deferral.
</objective>
