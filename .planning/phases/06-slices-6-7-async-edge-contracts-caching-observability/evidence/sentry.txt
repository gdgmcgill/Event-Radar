=== 1. Which transport proof was used ===

A3, the REAL SDK. src/server/__tests__/sentry.test.ts initializes @sentry/nextjs 10.75.3 inside Jest's
node project with the exact production options from sentryServerOptions(TEST_DSN) and one
substitution: an in-memory transport built with the SDK's own Sentry.createTransport, which parses
every envelope instead of sending it. The DSN host is under .invalid (RFC 2606). The default
integrations are narrowed to InboundFilters, FunctionToString, LinkedErrors, RequestData, Dedupe
(no process handlers, no http patching in the worker). The jest.mock fallback was NOT needed.
A positive control records the event as beforeSend receives it: it carries cookies, the body, the
query string, the email and the raw user id, so the "absent after scrubbing" rows are meaningful.
The proxy row drives the real proxy() with NEXT_PUBLIC_SUPABASE_URL unset (MissingEnvError in the
ring) and asserts one event tagged with the 500's x-request-id and route "/events".
