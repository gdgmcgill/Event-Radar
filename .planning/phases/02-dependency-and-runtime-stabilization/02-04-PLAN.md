<objective>
Batch 1: remove the root, not the leaves.

Of the 24 High/Critical packages in the production tree, seven are rooted in a CLI that no source file imports and six are rooted in a Swagger UI package with zero importers. Thirteen of twenty-four rows retire by deleting two lines from `package.json`. This batch deletes eleven dead declarations, pair-deletes one dead source file, moves one build-time package out of production dependencies, and captures the before side of the bundle-size comparison.

Purpose: The exit gate is phrased in vulnerability counts, which makes it tempting to start at the top of `npm audit --omit=dev` and work down. That produces weeks of churn, an unreviewable lockfile, and the two lines that would have retired thirteen rows still sitting there. `npm audit`'s own suggested fix for the Vercel CLI subtree is a 27-major jump of a CLI nothing calls. Removals come first, and they are driven by the Phase 1 reachability report, never by audit output order.
Output: eleven fewer declarations, one fewer source file, one package relocated, the STAB-04 decision note, and the STAB-16 before capture.
