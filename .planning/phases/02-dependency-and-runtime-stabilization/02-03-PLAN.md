The eight required clauses:

**Scope.** The production dependency tree, defined mechanically as the output of `npm audit --omit=dev --package-lock-only`. Name that command in the document so scope is a command and not a judgment.

**Moderate and Low.** Tracked in the Stage 2 completion note. Not blocking.

**Dev-only.** Recorded and re-checked, never blocking — **unless** the package also appears in the production tree. Name `baseline-browser-mapping` as the concrete case that forced this clause, since it is declared as a devDependency while `next` also depends on it transitively.
