REFAC-08 — proof that src/app/auth/callback/route.ts was never modified
======================================================================

Plan:     03-02
Phase:    03-refactor-foundations-schema-truth-and-the-seam-kit
Recorded: 2026-09-15

Why this file exists. A characterization plan creates a standing pressure to
edit the subject until the assertions pass (T-03-02-05). If that happens the
artifact stops being a contract and becomes a transcription of whatever shape
was convenient. The plan's central claim is therefore not "the tests pass" but
"the tests pass against code nobody touched", and that claim needs its own
evidence. Task 2 additionally applied nine deliberate mutations to this file and
restored each one; the hash below is taken AFTER all nine cycles completed.

------------------------------------------------------------------------------
6. How the restoration was performed
------------------------------------------------------------------------------

Every one of the nine mutation cycles restored the file with

    git checkout -- src/app/auth/callback/route.ts

and never by re-editing it by hand. The script then re-read the file and
asserted it was identical to the string captured before the first mutation,
aborting the whole run on any divergence. Nine hand-restorations is exactly how
a stray character survives into a commit, and this plan's whole claim is that it
did not.


------------------------------------------------------------------------------
7. What this proves, and what it does not
------------------------------------------------------------------------------

Proves: the eight characterized behaviours were read off unmodified source and
the assertions were fitted to the code, not the code to the assertions.

Does NOT prove: that the behaviours are correct, or desirable, or that they fire
in production. Two of them are tagged DEFECT. See
callback-characterization-note.md for the tagging and for the three coverage
caveats a later reader would otherwise get wrong.
