jest.config.js carries

    testPathIgnorePatterns: ['/node_modules/', '/.claude/', '/supabase/functions/tests/']

and the worktree's ABSOLUTE path contains '/.claude/', so every suite in the
worktree is filtered out. The canonical command reports:

    Running one project: node

That is not a property of these suites — it filters all 27 suites in the tree,
including the 20 that pre-date this plan. `npx jest --listTests` returns empty
in the worktree for the same reason.

The CLI flag overrides that one config value and restores the other two ignores
verbatim. Nothing else is changed, and jest.config.js is NOT edited — leaving it
alone is a phase-locked constraint of this plan. In the main checkout, which is
not under '/.claude/', the canonical command runs unmodified.
