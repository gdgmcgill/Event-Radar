================================================================================
RUN 3 — the audit-log metadata fix exposes a ripple
================================================================================

`logAdminAction`'s `metadata` parameter was narrowed from `Record<string,
unknown>` to the generated `Json`. That fixed src/lib/audit.ts(31,42) and
immediately produced an error that RUN 1 could not have shown, because a caller
was passing the widened type in:

src/app/api/admin/featured/[id]/route.ts(55,9): error TS2322: Type 'Record<string, unknown>' is not assignable to type 'Json | undefined'.
  Type 'Record<string, unknown>' is missing the following properties from type 'Json[]': length, pop, push, concat, and 35 more.

This is the TENTH error, and it is a genuine one rather than a regression: the
`updates` object is both the PATCH body for `featured_events` and the audit-log
metadata, and `unknown` admits values neither column can hold. Fixed by
narrowing the declaration to `Record<string, Json>` — narrowing, not widening.
