## What this count is FOR

This is the phase's "zero routes" tripwire. Plan 03-03 applies the seam to zero
routes, so this count must be **identical** at the end of this plan and at the
end of the phase. It fails in both directions on purpose:

  - a HIGHER count means a new file reached the service-role credential
  - a LOWER count means a route was quietly migrated to the seam, which this
    phase forbids (L3 / REFAC-05 / ROADMAP SC3)

`scripts/check-elevated-ratchet.mjs` (task 3) asserts the first direction on
every run and reports the second.
