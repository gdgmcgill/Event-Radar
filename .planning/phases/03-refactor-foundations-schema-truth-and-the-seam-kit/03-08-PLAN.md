<objective>
Wave 6: decide the one production write this phase could make, then write the note that lets a reader confirm Phase 3 from artifacts alone — including everything it did not close.

Purpose: the Stage 2 gate was not "the work is done", it was "a reader can confirm the work is done from artifacts alone, without re-running anything." Phase 3 is held to the same bar, and it is a higher bar than it sounds: it means every claim in the completion note quotes a committed file, and every requirement whose text has an unmet clause says which clause.

There is also one genuine decision left, and it belongs to a human rather than an executor. Marking the baseline version applied in production's migration history table is the phase's only production write. Nothing in the five success criteria requires it. It restores deployment continuity for any future push, and skipping it is an acceptable outcome that defers the repair to Phase 8's deployment certification. That is the phase owner's call, not the executor's, which is why this plan is not autonomous.

Output: a preflight capture of exactly what would be written, a human decision, the outcome either way, a deferred-items file, and the readiness note — plus the requirement-state updates in both registers.
