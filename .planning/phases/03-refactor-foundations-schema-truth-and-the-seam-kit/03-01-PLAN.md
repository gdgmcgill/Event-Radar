## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent runtime → production Postgres (MCP `execute_sql`) | A privileged transport authenticated by an OAuth grant the agent holds; untyped SQL crosses it |
| agent runtime → production Postgres (`sql-readonly.mjs` / Management API) | The sanctioned transport; `read_only: true` is enforced server-side outside the client's reach |
| laptop `.env.local` → production Postgres | `SUPABASE_SERVICE_ROLE_KEY` is present on disk and bypasses RLS for anything that reads it |
| production query output → committed `.planning/` evidence | Captures are committed and publicly readable; rows can carry refs, tokens and connection strings |
| repository tree → Vercel | The project is not git-linked; a push does not deploy; previews sit behind Deployment Protection |
| another project's Docker stack → this project's ports | Stopping a stack that is not ours is an action against state outside this repository |
