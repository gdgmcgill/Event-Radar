## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test runner → working tree | Jest and tsc can write caches and build-info files |
| captured output → git history | Test output can echo fixture data or environment values |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04-01 | Tampering | `tsconfig.tsbuildinfo`, Jest cache | mitigate | Both are gitignored on this repo; `readonly-guard.sh` runs after every capture and fails on any tracked-file change |
| T-01-04-02 | Tampering | Installing a missing test-environment package to make a suite pass | mitigate | The action forbids installing; a skipped suite is recorded with its reason and handed to STAB-08; the guard's lockfile hash check detects a violation |
| T-01-04-03 | Information Disclosure | Captured Jest output embedding a real environment value | mitigate | The phase-gate secret sweep in plan 01-13 greps `.planning/audit/baseline/` for JWT, secret-prefix, and connection-string shapes before the final commit |
| T-01-04-04 | Repudiation | A locked decision re-argued later without evidence | mitigate | The decision record cites captured files by path for every claim rather than asserting counts inline |
| T-01-04-SC | Tampering | npm/npx package installs | accept | `npx jest` and `npx tsc` resolve from the already-installed local tree; no registry fetch and no lockfile write, verified by the guard's hash check |
