## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous request → cron handler | A cron route with no confirmed credential is an unauthenticated entry point |
| one user's stored objects → another user | Path-prefix ownership is the only control on this boundary |
| external webhook sender → ingestion pipeline | An unverified webhook body reaches the database |
| public bucket URL → object content | A public bucket is readable by anyone holding the path |
