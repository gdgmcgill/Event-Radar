## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → local execution | One-shot fetched packages execute with full local filesystem access |
| npm read commands → lockfile | npm repairs lockfile metadata on read commands when the installed tree has drifted |
| public route → shipped dependency | An unguarded page importing a vulnerable package is the reachability question |
